# fastStorage Dataset

This work uses the GWA-T-12 Bitbrains dataset (fastStorage trace), a real-world dataset of virtual machine workload metrics collected from a distributed datacenter.

The dataset contains time-series performance data of virtual machines, including CPU usage, memory usage, disk I/O, and network throughput. It is widely used in research on cloud workload prediction and autoscaling.

Source:
https://www.kaggle.com/datasets/gauravdhamane/gwa-bitbrains
